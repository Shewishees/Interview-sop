# Task 2: STAR 全要素深度复盘与技术权衡对比矩阵 (STAR & Trade-off Matrix)

## 📌 任务定位
这是整个面试 SOP 的“杀伤力核心”。现代顶尖技术面试官最爱追问的不是“你做了什么”，而是“你为什么这么做？为什么不选方案 B？遇到致命边界怎么解决？”
本任务要求：
1. **一句话电梯演讲 (One-Sentence Pitch)**：15 秒打动面试官的高密度项目总结；
2. **纯文字 STAR 全要素复盘**：
   - Situation：面临的工业界/科研核心痛点；
   - Task：核心指标目标（如显存、PPL、训练稳定性、动作成功率）；
   - Action：结合代码库的硬核攻坚动作；
   - Result：亮眼、真实、可复现的量化业务收益；
3. **技术权衡对比矩阵 (Trade-off Matrix)**：
   - 针对核心决策点（如 MLP vs Q-Former，两阶段训练 vs 联合端到端，ReAct vs Plan-and-Solve，混合 RAG vs 纯向量检索）；
   - 包含：我方选型理由与优势、备选方案 B、为何不选方案 B、前沿可能演进技术；
4. **致命追问防踩坑 (Pitfalls & Countermeasures)**：
   - 面试官最可能设下的 2 个技术陷阱问题；
   - 踩坑危险揭秘；
   - 满分标准答辩话术。
