# Task 4: 专属定制化模拟面试官 Master Prompt 生成 (Mock Interviewer)

## 📌 任务定位
帮助候选人生成一份能够直接粘贴到任何大模型（如 ChatGPT、Claude 3.5 Sonnet、DeepSeek-V3 等）中，开启“真刀真枪”1v1 模拟面试的超级面试官 System Prompt。

## 🎯 核心要求
生成的 Prompt 必须具备极强的沉浸感与压迫感，严禁空洞与机械化：
1. **身份锚定 (Role & Identity)**：精准锁定【目标公司】、【具体业务线/应聘岗位】；支持资深极客面、高压面或架构师面风格；
2. **候选人工程基因透视 (Candidate Profile)**：必须把简历内容与代码库扫描到的真实硬核事实（模型参数、Loss 收敛数据、显存方案、数据工程指标）深度植入面试官记忆库；
3. **面试交互黄金准则 (Interaction Protocol)**：
   - 单轮单问，坚决禁止一次性甩出一大堆题目；
   - 步步紧逼，死磕候选人代码实现背后的技术选型与 Trade-off（如为什么不用方案B）；
   - 结构化 5 段式严厉诊断反馈：
     * 💡【本轮得分】：0-100 客观评分
     * 🔍【面试官评语】：真实代码深度与工程说服力点评
     * ⚠️【致命扣分/遗漏点】：指出遗漏的边界条件或认知漏洞
     * 🎯【满分示范话术】：工业级硬核答题示范
     * ❓【下一轮提问】：由浅入深层层递进的连续追问。

## 📁 输入与输出契约
- **输入**：标准候选人全景上下文 (`inputs/example_context.json`)
- **输出**：严格符合 `output_schema.json` 的 JSON 对象，包含 `mock_interviewer_prompt` 字段。
