# Task 5: 分轮次大厂高阶反向提问策略 (Reverse Interview)

## 📌 任务定位
“你还有什么想问我的吗？” 是每场大厂面试临近尾声时的黄金翻盘与定调环节。
平庸的提问（“公司加班多吗”、“日常主要做什么”）会直接拉低印象分；
真正高级的反向提问能够：
1. 展现候选人对大模型/多模态/Agent 前沿演进趋势的深度洞察；
2. 表达强烈的落地欲望与对工程痛点的敬畏；
3. 将“被考者”角色巧妙逆转为“未来同行合作伙伴”。

## 🎯 核心要求
根据目标公司、应聘岗位 JD 以及候选人的技术底色，分 3 个轮次定制提问清单：
1. **技术一面 / 二面（技术骨干 & 资深架构师）**：
   - 目的：展现底层技术敏锐度、工程严谨性与快速上手机会；
   - 关注：实际业务延迟 Latency、Benchmark 测评体系、数据闭环配比、算力开销。
2. **三面 / 业务总监面（部门负责人 / VP）**：
   - 目的：展现宏观战略视野、商业化落地思考与前沿架构演进认知；
   - 关注：Native Multimodal vs 统一自回归趋势、Agent 灵活性与风控确定性权衡、未来 1-2 年战略里程碑。
3. **HR 终面（HRBP / 人力资源专家）**：
   - 目的：展现高情商、稳定性、团队契合度与主动进取心；
   - 关注：新人成长导师 Mentor 机制、团队技术攻坚氛围与绩效晋升考评通道。

## 📁 输入与输出契约
- **输入**：标准候选人全景上下文 (`inputs/example_context.json`)
- **输出**：严格符合 `output_schema.json` 的 JSON 对象，包含 `sop_5_reverse` 列表。
