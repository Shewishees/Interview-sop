# Task 6: 30分钟临考极速抢分速记卡 (Cheatsheet)

## 📌 任务定位
面试前半小时是候选人记忆调动与情绪稳定的关键窗口期。
此时长篇大论只会增加心理负担，候选人最需要的是：
1. **必须倒背如流的硬核数字 (Key Numbers)**：涵盖张量维度、参数量级、数据集规模、训练显存与 Loss 收敛数值，脱口而出即是专业。
2. **临考不败防御金句与心理锚点 (Golden Rules)**：包括遇到超纲题如何逻辑兜底、如何由浅入深展开系统阐述、如何化被动为主动。

## 🎯 核心要求
1. **硬核数据卡 (key_numbers)**：
   - 提取 5 个最具杀伤力的硬核参数（必须基于候选人代码事实与目标岗位技术栈，如 CLIP 197 token、MLP 1.8M 参数、4卡 4090 FSDP ZeRO-3、PPL 收敛下降梯度、Code Interpreter 100% 精度等）；
   - 格式：`{"name": "...", "val": "..."}`。
2. **应答黄金法则 (golden_rules)**：
   - 提炼 3 条可直接落地的答题防线与破局心法（如三层推进回答法、遇盲区时的技术类比迁移法、强调合规与量化指标）。

## 📁 输入与输出契约
- **输入**：标准候选人全景上下文 (`inputs/example_context.json`)
- **输出**：严格符合 `output_schema.json` 的 JSON 对象，包含 `sop_6_cheatsheet` 字典。
