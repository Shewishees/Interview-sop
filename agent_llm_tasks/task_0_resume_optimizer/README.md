# Task 0: 简历靶向精修与高分子弹点重构 (Resume Optimizer)

## 📌 任务定位
作为前置的战前准备阶段，针对用户的目标岗位需求（JD），对候选人现有简历中的项目经历进行深度审视与诊断，挖掘出 3 大失分硬伤，并结合本地代码库透视出的真实技术细节，重写出具备强工业级决策感的 STAR 子弹点。

## 🧠 思维链推理指引 (Chain-of-Thought)
1. **对比识别**：
   - 提取简历中的项目名称与核心描述段落；
   - 提取目标 JD 中的核心硬技能（如：两阶段对齐训练、FSDP 多卡分布式加速、ReAct 规划、混合 RAG 等）。
2. **硬伤诊断 (Diagnosis)**：
   - 检查动词：是否包含大量“复现”、“参与”、“了解”等被动弱词？升级为主导决策词（如“主导架构重构”、“自主攻坚算法”）。
   - 检查量化指标：是否缺少具体的参数量、显存开销、吞吐延迟、困惑度 (PPL) 或准确率？从本地代码扫描事实中提取具体数字补充进去。
   - 检查壁垒：是否掩盖了关键工程算法（如 Tokenizer BPE 边界增量差值编码、ActionHead L1 回归损失、沙箱计算防幻觉）？
3. **输出重构**：
   - 为每个项目产出 3~4 条格式工整的子弹点（以【四字核心动作】开头）；
   - 确保严格输出符合 `output_schema.json` 的 JSON 格式。

## 🚫 防幻觉与红线禁忌
- **禁止无中生有**：所有涉及的硬件、显卡型号、模型参数规模，必须严格依据 `scanned_repositories` 与候选人真实简历，绝不能凭空捏造未做过的技术；
- **纯净 JSON**：输出必须为合法 JSON，以便上层流水线直接解析。

## 🔄 独立执行与重新写入简历流程 (Standalone Execution & Write-Back)
1. **输入文件**：
   - 专用输入数据：`input_context.json`
   - 完整待运行 Prompt：`agent_prompt.txt`（已拼装 System Prompt + 候选人真实 JD/简历/代码事实）
2. **Agent 交付产物**：
   - 请将符合 `output_schema.json` 的标准 JSON 保存至同目录下的 `output.json`；
3. **Web 页面一键重新写入**：
   - 用户在系统前端点击【装载 Agent 成果并重新写入简历】；
   - 系统将自动提炼所有项目的精修 STAR 子弹点，一键覆盖回填至“个人简历档案”输入框，实现简历实战实体的永久升级！
