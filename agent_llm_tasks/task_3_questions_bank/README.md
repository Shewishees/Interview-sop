# Task 3: 结合本地源码的大厂定制题库与加分锦囊 (Questions Bank)

## 📌 任务定位
大厂面试从不考脱离代码的空洞八股，而是“揪住你简历和代码里的一个具体实现往下追问到底”。
本任务要求根据候选人的代码库和简历事实，定制 4 道大厂真题：
1. **架构设计与多模态/Agent底座题**（如 CLIP forward 提取、BPE 分词差值编码、ReAct 规划循环）；
2. **底层显存优化与分布式工程题**（如 FSDP ZeRO-3 通信拓扑、LoRA 梯度反向传播算力与显存分析）；
3. **数据清洗与评估闭环题**（如 SA1B 图文质量评分、Domain Randomization Sim-to-Real）；
4. **极端生产故障排障与系统设计题**（如 Multi-Agent 死循环熔断、数值计算幻觉防范、Loss 突刺梯度裁剪）。

每道题目必须配备：
- `category`: 考题所属分类；
- `title`: 极具大厂真实面试风格的提问标题；
- `framework`: 按照【结论先行 -> 机制推演 -> 代码落地】三步法标准回答框架；
- `bonus_tip`: 让面试官眼前一亮的加分小技巧。
